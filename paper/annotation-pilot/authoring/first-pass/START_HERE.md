# First-pass instructions

This is a small development-material training exercise, not an exam or a claim about historical review. You have four neutral case tasks and locally retained source. The packet's selected locations are author-chosen prompts, not proof that a defect exists. A bounded “no issue supported,” “unknown,” or “disputed” answer is acceptable.

1. Read `rubric.md`. Copy `answer-form.blank.json` to your own response file; never alter the blank.
2. Record a pseudonymous participant ID, date, and actual start/end/pause/active times. Record Python/repository familiarity and per-case recognition honestly. No real name is needed. Null means unfilled, not unknown.
3. Work through A, B, C, D independently. Read `task.md`, then the target/context excerpts. The complete captured file is available as `source.txt`. Numbers before ` | ` are original line numbers; they are not code. An empty source line is displayed as `0148 |` without an extra trailing space. Any original trailing source whitespace is preserved immediately before the display-only `⟦EOL⟧` marker; that marker is not source code. Cite references like `A/source.txt:L378-L393`.
4. For each case, state a conditional rule only if supported. Identify applicability, an exception or similar-looking legal case, generic versus local knowledge, evidence limits, and an explicit judgment. If context is missing, name it. You do not have to invent a rule or a defect.
5. Keep source facts, deductions, assumptions, and source-author assertions separate. Do not fill in a missing contract from memory without marking it external/prior knowledge. “I would need X” is useful evidence of insufficiency.
6. Use only this folder and your own reasoning. Do not execute the supplied source, import dependencies, browse upstream, search the repository, consult another annotator, or use a model to fill your form. Report any accidental exposure or deviation; it does not erase the training value.
7. Submit and freeze your first response before opening any later materials. If unsure, choose unknown rather than waiting for a suggested answer. Record what is uncertain and what evidence could resolve it.

We suggest about 6 minutes per case for an initial trial, but do not rush to match a target. Record actual effort, pauses, and incomplete work. Full source is included for reference; no claim is made that all dependencies, callers, or historical context are present. Familiarity with the case or its version prevents a formal blind-response claim. This exercise's release order is not a historical as-of reconstruction.

The supplied code is vLLM source under Apache-2.0; see `LICENSE.txt` and `ATTRIBUTION.txt`. The file formats prevent accidental import, not deliberate execution. Exact historical identities are reserved for the coordinator's audit, but code itself may remain recognizable.
