# Construction execution status and remaining methodology gates

The primary planned estimand is single-update constrained transfer H versus U
under shared diagnosis, persistent representation, source/context budget and gate.
Its domain is predefined source opportunities, not autonomous issue discovery or
repeated learning. H/M is a separate practical comparison and remains unchanged.
There are no empirical construction results or efficacy estimates in this update.

The [offline construction module](../experiments/construction/README.md) now checks
configuration structure, authored freeze binding, chronology declarations, fixed
attempt order, source packet bindings, candidate cap, failure retention and replay
consistency. Unconfigured models and all real-source freezes fail closed. This is
a usable local test harness; it does not remove the empirical study's missing gates.
The existing temporal study schema remains unchanged.

## Method and threats

Freeze one common constructor configuration before further remaining-W0 source
exposure, then freeze the complete construction/rule ledger before any W1 content.
Record already exposed development cases as such. One attempt per eligible PR and
one retained candidate, deterministic ordering, no human rewrite and no fallback
candidate after rejection constrain selection. Semantic judgment remains subjective;
independent screening and rejected/missing-case retention are still necessary.

Before W1 review, lock the source-only opportunity roster and neutral common packets.
Select the first structurally valid finding in frozen PR/anchor order before its
correctness is disclosed. An earlier missing or malformed cell blocks selection;
Unknown or missing feedback does not justify replacing the index. Lock shared
feedback/diagnosis/gate before W2 content. The authored episode selector now checks structural first-index routing and separate
feedback binding; exposure auditing and actual review/judgment remain unimplemented.

Independent source truth and output-support assessment are distinct. All predefined
arm×repetition×opportunity slots retain missingness and failures. Citation identity
and source hashes do not establish semantic support: independent assessors must
check applicability, contracts, scope and reasoning, retaining unknown/disputed
judgments. Correct disposition with unsupported reasoning is not strict resolution.
No-alert/abstention cannot be treated as demonstrated legal-neighbor resolution.

Local digests detect mismatches, not fabricated declarations or exposure histories.
Reidentification, prior model/source exposure, incomplete source context, subjective
opportunity enumeration and dependent families constrain inference. Synthetic PRs,
clock values and configuration tests are implementation evidence only. A fixed checkout-local register now binds repository/freeze and each PR receipt
across output directories, rejecting replacement and omission. Recovery reuses only
registered receipts. Repository aliases, alternate checkouts, filesystem-owner
mutation and source misrepresentation remain outside this local guarantee; real
execution still requires authenticated study identity and exposure auditing.

## Concrete next gates

1. Bind the actual retained 38-PR metadata roster, complete permitted source packets,
   prior rejections and exposure audit to a versioned configuration. Do not acquire
   new sources or expose W1 merely to fill configuration fields.
2. The raw-response parser now rejects duplicate keys and unsafe/unorderable
   spans, verifies anchors and quotes against pinned authored bytes, and rejects
   extra structural fields. Authored screening binds the retained first candidate,
   preserves rejected/missing/unknown/disputed outcomes and forbids replacement.
   These are implemented and regression-tested in `construction-raw-response` and
   `construction-screening`; they do not detect natural-language compound rules
   automatically or supply independent human screening. Remaining work is actual
   semantic assessment, authenticated study identity/exposure auditing and registry
   durability review before any real executor is connected.
3. Exact-key family grouping and construction-to-episode membership binding are now
   implemented for authored receipts. Independently audit semantic admission and
   lineage; audit the now-persisted authored index/feedback lock against authenticated study
   identity and exposure evidence before any real W1 material is used.
4. Bind neutral packets and independent semantic-support sidecars to existing
   annotation/observation records; validate missing/conflicting assessor handling.
5. Only in a separately configured execution stage bind actual constructor model,
   version, seed, decoding, token/time accounting and environment. Authentication
   is relevant to that stage, not a prerequisite for items 1–4. No present credential
   or model value is guessed or marked frozen.

The [system method](construction-and-episode-method.md) specifies stage ordering,
once-only slot semantics, registry trust, failure accounting and empirical gaps.
