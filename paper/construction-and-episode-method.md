# Construction, episode selection and execution boundaries

## Study system and estimand

The planned primary comparison is a single update under H (hard restriction) versus
U (unrestricted editing), sharing diagnosis, initial rule, persistent representation,
allowed evidence, resource envelope and acceptance gate. It estimates constrained
transfer on an independently predefined opportunity roster. It does not estimate
autonomous defect discovery, full-repository recall or repeated-learning benefit.
The practical M comparison is separate and its implementation is unchanged here.
No empirical efficacy result, independent annotation or model execution is reported.

The system proceeds through distinct locks. First enumerate the source frame and
record earlier development exposure. Freeze constructor instructions and operational
configuration before further construction-source exposure. Construct at most one
retained candidate per ordered PR slot, independently assess eligibility, then lock
the complete W0 family ledger before W1 content. Independently enumerate neutral W1
opportunities, perform a common old-rule review, lock the index finding before
correctness feedback, and adjudicate that fixed index. Lock feedback, diagnosis and
gate before W2 content. Finally evaluate the accepted single-update states on fixed,
independently judged W2 opportunities and report every missing or failed output slot.
These are required study stages, not assertions that they have occurred.

## What one construction means

One construction slot is one PR in the frozen repository/configuration roster,
consuming one original response (including malformed or interrupted responses).
The authored adapter imports response objects; it does not invoke a constructor.
The first retained candidate is determined by source path bytes, before/after side,
line interval and canonical digest. Extra candidates remain excluded records;
exact duplicates are separately marked. Invalid candidate structure fails the
entire slot rather than enabling a more attractive candidate. Human rewriting,
repeated prompts, new random seeds and a second candidate after rejection are not
permitted substitutes for the consumed slot. A genuinely new development version
must remain outside this frozen cohort and retain the original disposition.

The implementation preserves the full PR roster, original receipt and packet digest.
Completed empty responses mean `no_rule`; absent work means `not_run`. Neither
means the source is safe. Retention is provisional pending independent semantic
admission: a digest and valid span shape do not prove the path exists, the invariant
is substantive, or its rationale follows from the permitted code and contracts.

## Register, concurrency and recovery

The checkout-local register binds one freeze per declared repository and one exact
receipt per PR. It is independent of output-directory names. A cohort lock covers
scanning and binding; exclusive writes refuse replacement. Copies of output files
are checked against authoritative receipts. An already consumed slot cannot be
hidden by submitting a shorter prefix. Identical receipts may be replayed to rebuild
a report; this is not a new construction or additional experimental observation.

Recovery materializes registered receipts only. If a process dies after successful
registration but before report completion, the same inputs can rebuild the report.
A corrupt/partial registration or surviving lock blocks automatic recovery. It needs
an explicit integrity audit, not deletion and retry. Later prefix extensions make
older shortened reports incomplete relative to the current register; verification
requires recovery of the complete current prefix.

This guarantee assumes one trusted checkout and stable declared repository identity.
It does not authenticate a researcher, prevent an owner from modifying files/code,
unify another checkout, detect repository aliases, prove historical visibility or
guarantee fsync durability through power loss. The `authored/` namespace is an error
barrier, not proof that supplied bytes are synthetic. Real-source origins and model
configurations remain blocked even when their declared fields are complete.

## Deterministic episode index and feedback separation

The authored [episode selector](../experiments/construction/episode-selection.ts)
implements a separate structural stage. It receives a chronologically ordered PR
roster and deterministic family roster, and emits the full family×PR matrix.
Every cell binds the exact plan, rule and packet digests; duplicate exact-rule
families are rejected so a second family ID cannot duplicate the denominator. For
each family, complete no-finding cells permit continuation. The first cell containing
structurally valid findings supplies one index, sorted by path/side/span/digest.
A missing earlier cell, failed response, wrong packet/time binding or any malformed
finding blocks selection instead of skipping to the next PR. All later cells and
raw failures remain in the report even after an index is chosen. No FP/TP preference
or anticipated transfer effect enters the selection function.

Correctness feedback is a second function with a strict binding to the chosen
index and lock digest. Declared feedback time must follow the index lock. Unknown,
disputed, missing feedback or failed remaining gates block the episode; none permits
using a later finding. TP indices are retained rather than replaced with FP cases.
An empty required endpoint denominator remains unestimable. The selector does not
open source files or run a review. Its `ready_authored_only` status exercises routing
with synthetic gates; it never authorizes empirical evaluation.

The index digest is a reproducible logical binding, not an authenticated timestamp
or an externally registered freeze. Direct selector calls now validate the construction register but do not persist
index choices; the CLI uses a fixed local index/feedback register that rejects changed requests
across calls. Original requests precede derived outputs, permitting report recovery
without review reruns. Unknown or finalized missing feedback cannot be replaced.
Partial records or locks require an integrity audit rather than automatic takeover.
The same checkout/identity trust assumptions as construction apply. Its times and
judgments remain invented fixture values; real admission still needs authenticated
study identity, external exposure auditing and independent feedback.

## Failure and missingness accounting

| Event | Preserved disposition | Forbidden inference/action |
| --- | --- | --- |
| Source packet absent | `not_run` / missing evidence | Safe source or zero rule yield |
| Invalid/interrupted construction | Failed consumed slot | Retry with replacement response |
| Candidate cap exceeded | First retained provisionally; extras recorded | Pick best supported extra |
| Earlier review cell missing/malformed | Index selection blocked | Skip to later favorable finding |
| Complete review with no finding | Continue in fixed order | Fabricate a finding/feedback label |
| Index correctness Unknown/disputed | Index retained, episode blocked | Replace index or force judgment |
| TP index without false-alarm denominator | Retain composition; endpoint unestimable | Switch to FP-only sampling |
| Missing/failed arm output | Preserve opportunity and output slot | Drop from denominator or count as resolution |

Every source judgment remains separate from output-support judgment. Independent
assessors must establish the actual claim's applicability, contract, scope and
reasoning from common permitted evidence. Citation IDs, matching digests or a correct
label with an unsupported explanation do not establish supported strict resolution.
No-alert and abstention cannot alone resolve a legal-neighbor opportunity.

## Remaining empirical requirements and threats

The offline checks establish structural behavior only. Episode family rosters now bind the complete authoritative construction report,
freeze digest and every retained PR/candidate member. Exact semantic keys merge
with all members preserved; invented or omitted families are rejected. This closes
the authored dataflow connection, while retained candidates still lack independent
semantic admission. The register enforces construction completion before selection
in the local call sequence, not independently verified historical timestamps. Still required are actual
real-source provenance and semantic verification (the authored raw-response parser
already rejects duplicate keys and verifies span/quote bindings), independent
compound-rule assessment, independent eligibility
and lineage review, authenticated construction/index locks, neutral opportunity
packets and independently locked source/support judgments. Model/version/decoding,
resource measurement and execution configuration are unconfigured; their absence
does not prevent further offline testing. No model identity is guessed.

Selection remains conditional on the inspected development frame and manually
predefined opportunities. Source and model pretraining exposure, reidentification,
missing context, dependent families, opportunity omissions and subjective assessment
limit generalization. Record these limitations and all exclusions instead of using
synthetic routing tests as evidence of real labels, independence or effectiveness.
